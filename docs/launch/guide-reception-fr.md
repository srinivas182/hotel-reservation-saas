# Guide de la réception — Assistant WhatsApp

_First Class Lodge · Version pilote_

## 1. Ce que fait l'assistant

L'assistant répond aux clients sur le numéro WhatsApp de l'hôtel, en français ou en anglais, avec les vrais prix et les vraies disponibilités. Il peut :

- répondre aux questions (chambres, prix, petit-déjeuner, paiement, itinéraire…) ;
- envoyer une **demande de réservation** à la réception et bloquer les chambres.

Il **ne confirme jamais** une réservation : c'est toujours vous qui décidez. Quand il ne sait pas, ou si le client se plaint, demande une personne ou parle d'un groupe, il **vous passe la conversation**.

## 2. Votre écran du jour (« Aujourd'hui »)

- **Demandes de réservation WhatsApp** en haut : à traiter en priorité. Chaque demande indique le client, le séjour, le prix annoncé, le prix actuel et l'heure jusqu'à laquelle les chambres sont bloquées.
- Arrivées, départs, clients présents, chambres libres ce soir : comme d'habitude.
- Cliquez sur « M'alerter sur cet ordinateur » pour recevoir une notification à chaque nouvelle demande.

## 3. Traiter une demande

1. Vérifiez la demande (dates, nombre de personnes, catégorie).
2. **Approuver** : la réservation est créée et le client reçoit automatiquement la confirmation (ou les instructions d'acompte si l'hôtel demande un acompte).
3. **Modifier puis approuver** : changez la catégorie, les dates, le nombre de chambres. Un changement de prix demande l'autorisation et une raison.
4. **Refuser** : choisissez la raison (complet, dates impossibles, autre). Le client est prévenu.

Si le prix a changé depuis que le client l'a reçu, cochez « Approuver au nouveau prix » après avoir vérifié.

**Délai** : répondez avant l'heure affichée. Sinon la demande expire, les chambres sont libérées, le client est prévenu que la réception va le contacter, et la conversation passe en « À traiter ».

## 4. La boîte de réception

- **À traiter** (rouge) : l'assistant vous a passé la conversation. La raison est affichée (plainte, demande d'une personne, groupe…).
- **Prendre la main** : la conversation vous est attribuée, l'assistant se tait.
- **Rendre la main à l'assistant** : quand c'est réglé.
- **Les miennes** : les conversations qui vous sont attribuées.
- **Note interne** : visible uniquement par l'équipe (par exemple « client rappelé à 10 h »).
- **Traduire en anglais** : écrivez en français, cliquez, **relisez**, puis envoyez.
- **Afficher en français** : sous un message de client écrit dans une autre langue.

Après 24 heures sans message du client, WhatsApp n'autorise plus les messages libres : utilisez un **modèle** (liste « Modèle », puis « Envoyer le modèle »).

## 5. Mode supervisé (première semaine)

Pendant la première semaine, l'assistant **prépare** ses réponses mais ne les envoie pas. Vous les voyez dans la conversation avec la mention « Brouillon de l'assistant » :

- **Envoyer** si la réponse est bonne ;
- **Éditer** puis envoyer si elle doit être corrigée ;
- **Écarter** si elle ne convient pas (puis répondez vous-même).

Vos choix servent à décider quand passer en mode automatique.

## 6. Ce que vous ne devez jamais faire

- Demander un numéro de carte bancaire ou de passeport sur WhatsApp.
- Confirmer une réservation sans l'avoir approuvée dans le système.
- Laisser un client sans réponse : si vous êtes occupé, une réponse courte (« Je reviens vers vous dans 10 minutes ») suffit.

## 7. En cas de problème

| Situation                               | Que faire                                                                                                              |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| L'assistant répond mal ou bizarrement   | Prenez la main sur la conversation, puis prévenez le responsable.                                                      |
| Plus aucun message n'arrive             | Prévenez le responsable : il peut désactiver l'assistant ; vous répondez alors depuis l'application WhatsApp Business. |
| Message « WhatsApp n'est pas connecté » | Le propriétaire doit reconnecter WhatsApp (Paramètres → WhatsApp).                                                     |
| Une demande a expiré                    | Appelez ou écrivez au client (modèle si plus de 24 h).                                                                 |
