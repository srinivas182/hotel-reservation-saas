# Aide-mémoire réception — Assistant WhatsApp

**Chaque matin** : ouvrez « Aujourd'hui » · activez « M'alerter sur cet ordinateur ».

**Demande de réservation WhatsApp** → vérifiez → **Approuver** / **Modifier puis approuver** / **Refuser**. Avant l'heure affichée.

**« À traiter » dans la boîte de réception** → **Prendre la main** → répondez → **Rendre la main à l'assistant**.

**Brouillon de l'assistant** (mode supervisé) → **Envoyer** · **Éditer** · **Écarter**.

**Client en anglais** → écrivez en français → **Traduire en anglais** → relisez → envoyez.

**Plus de 24 h sans message du client** → **Modèle** puis **Envoyer le modèle**.

**Note interne** → visible par l'équipe uniquement.

**Jamais** : numéro de carte ou de passeport · confirmer sans approuver dans le système · laisser un client sans réponse.

**Problème** : prenez la main · prévenez le responsable · en dernier recours, l'assistant peut être désactivé et vous répondez depuis WhatsApp Business.
