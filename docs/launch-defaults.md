# Launch defaults

Starting values chosen from common practice for B2B software in West Africa. **Every one can be changed later** — where it lives is given for each. Apply them with `php artisan launch:defaults` (safe to run again; it never overwrites a choice already made).

Packs: 1 000 AI credits 10 000 FCFA, 5 000 for 40 000, 2 000 emails 5 000. 14-day trial on Pro | Below a part-time receptionist's monthly cost; yearly discount is the usual 2 months | Platform → Billing → Plans                             |
